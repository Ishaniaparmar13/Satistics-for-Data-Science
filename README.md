3. Problem Statement 
To create and analyse a student dataset using Pandas and NumPy, perform basic 
DataFrame operations, convert numerical data into NumPy arrays, perform matrix 
operations, calculate shape, size and dimensions, and encode categorical variables 
using One-Hot Encoding.

5. Solution 
The problem is solved using Python with the help of the Pandas, NumPy, and 
Scikit-learn libraries. A student dataset is created and stored in a Pandas 
DataFrame. The data is explored using DataFrame functions, numerical columns 
are converted into NumPy arrays, and different matrix operations are performed. 
Finally, categorical variables such as Gender and Department are converted into 
numerical form using One-Hot Encoding.
